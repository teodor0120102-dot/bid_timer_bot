# BidTimerBot

Таймер ставок для Telegram-групп с режимом **«Сообщения за Stars»**.

## Что настраивать

**В Railway нужен только токен** — один раз при деплое:

```
BIDTIMER_BOT_TOKEN=токен_от_BotFather
```

Всё остальное работает автоматически:

- права берутся из Telegram — **владелец и админы** чата управляют ботом сразу;
- цена Stars подтягивается из настроек группы;
- при добавлении бота в чат он сам пришлёт инструкцию.

### В группе

1. Добавь бота и сделай **администратором**.
2. Включи **Сообщения за Stars** (Настройки → Права).
3. Запусти раунд: `/bid start`

## Команды

| Команда | Действие |
|---|---|
| `/bid` | Справка |
| `/bid start [сек]` | Запуск раунда |
| `/bid stop` | Остановка |
| `/bid status` | Статус |
| `/bid add @user` | Дать доступ обычному участнику |

Алиасы: `/start`, `/go`, `/старт`, `/stop`, `/timer_*`.

## Запуск локально

```powershell
pip install -r requirements.txt
$env:BIDTIMER_BOT_TOKEN="ВАШ_ТОКЕН"
python bot.py
```

## Railway

- **Root Directory:** `bid_timer_bot`
- **Start:** `python bot.py`
- **Variables:** только `BIDTIMER_BOT_TOKEN`
